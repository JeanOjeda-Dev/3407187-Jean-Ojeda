## 📊 APP CONTABILIDAD PYMEs - week-03

**Sistema de Gestión Financiera Integral para el Sector Empresarial**

Este proyecto constituye el único entregable obligatorio de la **Semana 03** del programa ADSO. Consiste en un motor de cálculo financiero ejecutado en consola, diseñado para automatizar operaciones aritméticas, validaciones de seguridad y proyecciones de crecimiento para pequeñas y medianas empresas, aplicando estándares de **JavaScript ES2023**.

---


## 🛠️ Especificaciones de Desarrollo (Requisitos Cumplidos)

El núcleo del sistema ha sido actualizado bajo los estándares solicitados, integrando los siguientes conceptos técnicos avanzados:

* **Operadores Aritméticos y Potencia:** Cálculo de utilidad neta y proyecciones de crecimiento compuesto mediante el operador `**` y el uso de paréntesis para manejar la precedencia.
* **Asignación Compuesta:** Gestión dinámica del flujo de caja (ingresos, gastos, intereses y reservas) utilizando los operadores `+=`, `-=`, `*=` y `/=`.
* **Comparación Estricta:** Implementación obligatoria de `===` y `!==` para la validación de roles administrativos y estados de facturación, eliminando el uso de comparaciones débiles.
* **Lógica y Control de Estados:** Aplicación de operadores lógicos `&&`, `||` y `!` para determinar permisos de acceso y disponibilidad del sistema según el saldo y el perfil del usuario.
* **Gestión de Coerción:** Uso de conversiones explícitas con `Number()` para prevenir errores de concatenación accidental y garantizar la precisión en cálculos monetarios.

## 🚀 Funcionalidades Evaluadas en el Script

1. **Cálculo de Utilidad Neta:** Algoritmo que deduce costos operativos e impuestos de forma automatizada.
2. **Proyección a Largo Plazo:** Estimación de ventas futuras basada en tasas de crecimiento porcentual.
3. **Auditoría de Movimientos:** Reporte visual de la evolución del saldo bancario tras aplicar múltiples transacciones.
4. **Validación de Seguridad:** Filtro de acceso basado en el rol de usuario y el estado activo de las entidades contables.
